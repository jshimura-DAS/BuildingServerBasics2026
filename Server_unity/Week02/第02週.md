## データ型の分類
言語が提供するデータ型は、**単一の値を扱う型**と**複数の値を扱う型**に大別できる。
ここでは複数の値を扱う型に焦点を当てる。

### 1. 配列に近い型: リスト（list）
リストは**順序あり・変更可能**なコレクション。ゲームのスコア一覧、ログ一覧などに向く。

```python
# list_sample.py
scores = [1200, 980, 1430, 1100]

scores.append(1250)          # 末尾追加
top_score = max(scores)      # 最大値
avg_score = sum(scores) / len(scores)

print("scores:", scores)
print("top:", top_score)
print("average:", round(avg_score, 1))
```

実行例:
```bash
python3 list_sample.py
```

#### リストの要素を1つずつ処理する（for）
`for`は、リストの要素を先頭から順に取り出して、同じ処理を繰り返す。書き方は目的によって使い分ける。

**書き方1: 要素を直接取り出す（最も基本）**

```python
# list_for1.py
scores = [1200, 980, 1430, 1100]

for s in scores:
    print("score:", s)
```

- 要素の値だけが必要なときに使う。最も短く読みやすい。

**書き方2: 添字（インデックス）で取り出す**

```python
# list_for2.py
scores = [1200, 980, 1430, 1100]

for i in range(len(scores)):
    print(i, scores[i])
```

- `range(len(scores))`は`0, 1, 2, 3`を順に作る。
- 位置番号が必要なとき、リストの要素を書き換えたいときに使う。ただし、書き方3の方が簡潔に書ける場合が多い。

**書き方3: 番号と要素を同時に取り出す（enumerate）**

```python
# list_for3.py
scores = [1200, 980, 1430, 1100]

for i, s in enumerate(scores, start=1):
    print(f"{i}人目: {s}")
```

- `enumerate`は`(番号, 要素)`の組を作る。`start=1`で番号を1から始められる。
- 「1位、2位…」のような順位表示に向く。

**書き方4: 条件付きで処理する（for + if）**

```python
# list_for4.py
scores = [1200, 980, 1430, 1100]

for s in scores:
    if s >= 1100:
        print(s, "は合格")
    else:
        print(s, "は不合格")
```

**書き方5: 内包表記（新しいリストを作る）**

```python
# list_for5.py
scores = [1200, 980, 1430, 1100]

bonus_scores = [s + 100 for s in scores]
high_scores = [s for s in scores if s >= 1100]

print(bonus_scores)
print(high_scores)
```

- `[式 for 変数 in リスト]`: 全要素に処理を行った新しいリストを作る。
- `[式 for 変数 in リスト if 条件]`: 条件に合う要素だけを集める。
- 元のリストは変更されない。

**書き方の使い分け**

| 目的 | 書き方 |
| ---- | ------ |
| 要素の値だけ使う | 書き方1 |
| 番号も使う（順位表示など） | 書き方3 |
| 添字で位置を指定して書き換える | 書き方2 |
| 条件に合う要素だけ処理する | 書き方4 |
| 加工・抽出した新しいリストを作る | 書き方5 |

#### 範囲を指定して取り出す（スライス）
リストは添字で位置を指定する。**先頭の添字は0**で、`-1`は末尾を表す。`:`を使うと、範囲をまとめて取り出せる。

```python
# list_slice.py
scores = [1200, 980, 1430, 1100, 1250, 900]
#  添字:     0     1     2     3     4    5

print(scores[0])      # 1200（先頭）
print(scores[-1])     # 900（末尾）

print(scores[1:4])    # [980, 1430, 1100]（1以上4未満）
print(scores[:3])     # [1200, 980, 1430]（先頭から3個）
print(scores[3:])     # [1100, 1250, 900]（3番目から最後まで）
print(scores[-3:])    # [1100, 1250, 900]（末尾から3個）
print(scores[::2])    # [1200, 1430, 1250]（1つおき）
print(scores[::-1])   # [900, 1250, 1100, 1430, 980, 1200]（逆順）
```

書式は`リスト[開始:終了:間隔]`。

- 開始は含み、**終了は含まない**（`[1:4]`は添字1, 2, 3）。
- 省略すると、開始は先頭、終了は末尾、間隔は1になる。
- スライスは新しいリストを返す。元のリストは変わらない。

実用例: スコア降順に並べたリストから上位3件を取り出す。

```python
# list_top3.py
scores = [1200, 980, 1430, 1100, 1250, 900]

top3 = sorted(scores, reverse=True)[:3]
print("上位3件:", top3)
```

#### 条件を使った範囲指定（抽出）
`:`による指定は**位置**での範囲指定。**値の条件**で絞り込むときは、`if`を使う。

```python
# list_filter.py
scores = [1200, 980, 1430, 1100, 1250, 900]

# 1000以上のスコアだけ抽出
passed = [s for s in scores if s >= 1000]

# 1000以上1300未満（範囲条件）
middle = [s for s in scores if 1000 <= s < 1300]

# 条件に合う要素の件数と合計
print("1000以上:", passed)
print("1000以上1300未満:", middle)
print("件数:", len(passed), "合計:", sum(passed))
```

- Pythonでは`1000 <= s < 1300`のように、範囲条件を連続して書ける。
- 位置で絞る→スライス`[:]`、値で絞る→`if`付きの内包表記（または`for`と`if`）、と使い分ける。

#### 実習
上の各サンプルを`~/class_python`に保存して`python3 ファイル名`で実行し、出力が説明と一致することを確認する。`scores`の中身や、`[1:4]`の数字を変えて、結果がどう変わるか試す。

### 2. タプル（tuple）
タプルは**順序あり・変更不可**なコレクション。座標、固定設定値など「変えてはいけない値」の管理に向く。

```python
# tuple_sample.py
spawn_point = (10, 20, 5)  # x, y, z

x, y, z = spawn_point
distance_hint = x + y + z

print("spawn:", spawn_point)
print("x:", x, "y:", y, "z:", z)
print("distance_hint:", distance_hint)
```

### 3. 辞書（dict）
辞書は**キーと値**の対応で管理する型。JSONに近く、API開発で頻出。

```python
# dict_sample.py
player = {
	"name": "PlayerA",
	"level": 7,
	"hp": 85
}

player["hp"] -= 20
player["items"] = ["Potion", "Key"]

print("name:", player["name"])
print("hp:", player["hp"])
print("items:", player["items"])
```

### 4.集合型(set)
集合型は**順序なし・重複なし**のコレクション。ユニークな値の管理に向く。
重複したものを除外したい場合に便利で、リストやタプルのように順序を気にしない場合に使う。

```python
# set_sample.py
unique_items = {"Potion", "Key", "Sword", "Shield"}
unique_items.add("Arrow")
print("unique_items:", unique_items)
unique_items.add("Potion")
print("unique_items:", unique_items)
```

### 5. データ型の使い分け
それぞれの型で特徴を整理すると以下の通り。
| データ型 | 特徴        | 用途例           |
| ---- | --------- | ------------- |
| リスト  | 順序あり・変更可能 | スコア一覧、ログ一覧    |
| タプル  | 順序あり・変更不可 | 座標、固定設定値      |
| 辞書   | キーと値の対応   | JSON、APIレスポンス |
| 集合型  | 順序なし・重複なし | ユニークな値の管理     |

## 関数の定義と使い方

関数は、何度も使う処理をまとめて、名前を付けて再利用するもの。C#の`def`に相当します。

### 基本形

```python
def 関数名(引数1, 引数2):
    処理
    return 返り値
```

### 簡単な実例

```python
# calc_damage.py
def apply_damage(hp, damage):
    """HPからダメージを引いて、新しいHP を返す関数"""
    new_hp = hp - damage
    return new_hp


def is_alive(hp):
    """HPが0より大きいかどうかを返す関数"""
    return hp > 0


# 関数を使う（関数の呼び出し）
current_hp = 100
damage_taken = 30

current_hp = apply_damage(current_hp, damage_taken)
print(f"ダメージを受けた。HP: {current_hp}")

if is_alive(current_hp):
    print("まだ戦闘続行可能")
else:
    print("戦闘終了")
```

実行結果:
```text
ダメージを受けた。HP: 70
まだ戦闘続行可能
```

**ポイント:**
- `def`で関数を定義し、`return`で値を返す。
- 関数内のドキュメント文字列（`""" ... """`）は、その関数の説明。
- 関数を使うときは、関数名`()`で呼び出す。

### 複数の処理を関数にまとめる

データ処理は、より大きな流れになります。スコア計算の例：

```python
# score_functions.py
def calculate_final_score(base, bonus, penalty):
    """最終スコアを計算"""
    final = base + bonus - penalty
    return final


def assign_rank(score):
    """スコアからランク判定を実施"""
    if score >= 1000:
        return "A"
    elif score >= 800:
        return "B"
    else:
        return "C"


def display_result(name, score, rank):
    """結果を整形して表示"""
    print(f"{name}: スコア {score}, ランク {rank}")


# 使用例
base_score = 1200
bonus = 350
penalty = 100

final_score = calculate_final_score(base_score, bonus, penalty)
rank = assign_rank(final_score)
display_result("PlayerA", final_score, rank)
```

実行結果:
```text
PlayerA: スコア 1450, ランク A
```

### エントリーポイントと関数の配置

Pythonでプログラムを実行すると、**上から順に実行**されます。関数を途中で定義した場合、以下の流れになります。

```python
# example_entry.py
print("1. プログラム開始")


def greet(name):
    return f"こんにちは、{name}さん"


print("2. 関数定義後")

# ここで関数を呼び出す
message = greet("Taro")
print(message)

print("3. プログラム終了")
```

実行結果:
```text
1. プログラム開始
2. 関数定義後
こんにちは、Taroさん
3. プログラム終了
```

**エントリーポイント（プログラム開始点）:**
- `python3 example_entry.py` で実行すると、ファイルの**1行目から順に実行される**。
- `def greet():`は関数の定義であり、この行で実行は止まらず、スキップして次へ進む。
- 関数内のコードは、`greet()`が呼び出されるまで実行されない。

### 関数の有無でエントリーポイントが変わる

**関数がない場合:**

```python
# no_function.py
hp = 100
damage = 30
hp -= damage
print(f"HP: {hp}")
```

実行:
```bash
python3 no_function.py
# 出力: HP: 70
```

→ ファイルの1行目からコードが実行される。

**関数がある場合:**

```python
# with_function.py
def take_damage(hp, damage):
    return hp - damage


if __name__ == "__main__":
    hp = 100
    damage = 30
    hp = take_damage(hp, damage)
    print(f"HP: {hp}")
```

実行:
```bash
python3 with_function.py
# 出力: HP: 70
```

→ `def take_damage()`は読み込まれるだけで、`if __name__ == "__main__":`ブロックの中身が実行される。

### 補足: `if __name__ == "__main__":` の役割

Pythonファイルが直接実行される場合と、別ファイルから読み込まれる場合で、実行する内容を切り分けるための手法。第03週のFlask例と同じ考え方。

**`__name__`とは:**

- ファイルを直接実行した場合: `__name__ == "__main__"` （文字列として`"__main__"`）
- 別ファイルから`import`された場合: `__name__`はそのモジュール名（例：`"game_utils"`）

**実例:**

```python
# utils.py
def greet(name):
    return f"こんにちは、{name}"

if __name__ == "__main__":
    # 直接実行時のみこのブロックが動く
    print(greet("Taro"))
```

実行方法：

```bash
# utils.py を直接実行
python3 utils.py
# 出力: こんにちは、Taro
```

別ファイルから読み込む場合：

```python
# main.py
from utils import greet

# utils.py の __name__ は "utils" となり、
# if __name__ == "__main__": ブロックは実行されない
print(greet("Hanako"))
# 出力: こんにちは、Hanako
```

**利点:**

- ユーティリティ関数を定義したファイルを、単体でテスト実行できる。
- 別ファイルから読み込まれたときに、余計なコードが実行されない。
- 第03週のFlask起動のように、プログラムの開始点を明確にできる。

### 関数をモジュール化（別ファイルで再利用）


関数の利点は、**別ファイルから読み込んで（import）再利用できる**こと。

```python
# game_utils.py（ユーティリティ関数をまとめたファイル）
def apply_damage(hp, damage):
    return max(0, hp - damage)  # HPが負にならないように調整


def is_alive(hp):
    return hp > 0
```

```python
# main.py（メインプログラム）
from game_utils import apply_damage, is_alive

player_hp = 100
player_hp = apply_damage(player_hp, 30)

if is_alive(player_hp):
    print("戦闘続行")
else:
    print("ゲームオーバー")
```

→ `game_utils.py`を`import`して、その中の関数を使う。このとき、`game_utils.py`のコードは定義部分だけが読み込まれ、**直接実行されない**。

### 関数定義の置き場所に関する注意

```python
# ❌ 間違い：関数より下で呼び出す前に定義していない
greet("Taro")  # ❌ ここでエラー："greet" is not defined

def greet(name):
    return f"こんにちは、{name}"
```

```python
# ✅ 正しい：関数を先に定義してから呼び出す
def greet(name):
    return f"こんにちは、{name}"

greet("Taro")  # ✅ 成功
```

**ただし、`if __name__ == "__main__":`ブロックが使用されている場合は例外:**

```python
# ✅ こちらは OK：関数定義より下で呼び出すが、__main__ブロック内なので実行時に定義済み
def greet(name):
    return f"こんにちは、{name}"

if __name__ == "__main__":
    greet("Taro")  # ✅ 定義済みなので成功
```
