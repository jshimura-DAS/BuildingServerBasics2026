## 1. Flaskとは
Flaskは、Pythonで書かれた**軽量なWebフレームワーク**。数行のコードでWebサーバー機能を持つプログラムを作れる。

- 必要最小限の機能だけを持ち、必要に応じて拡張する設計（マイクロフレームワーク）。
- URLと関数を対応付けるだけで、Webページ・Web APIを作れる。
- 第04週以降で、第02週で学んだ辞書をJSONとして返すWeb APIに発展させる。

### Webフレームワークとは
Webサーバー開発で共通して必要な処理（リクエストの受け取り、URLごとの振り分け、レスポンスの返却）を部品としてまとめたもの。自前で通信処理を書かずに、「どのURLで何を返すか」に集中できる。

## 2. Flask と PHP + Apache の違い
Webサーバーを作る方法は複数ある。代表的なPHP + ApacheとFlaskを比較する。

| 項目 | PHP + Apache | Python + Flask |
| ---- | ------------ | -------------- |
| 言語 | PHP | Python |
| Webサーバーの役割 | Apacheが常時稼働し、リクエストを受けてPHPを呼び出す | Pythonプログラム自身がサーバーとして待ち受ける（開発用サーバー） |
| URLの決まり方 | ファイルの置き場所（`/var/www/html/index.php`など） | コード上のルーティング（`@app.route`） |
| 1リクエストの流れ | Apache → PHP処理 → 応答 | Flask（Python関数）→ 応答 |
| 設定 | Apacheの設定ファイルが必要 | Pythonコードのみで開始できる |
| 得意分野 | 従来型のWebページ配信 | Web API、Pythonのデータ処理との連携 |

要点:
- PHP + Apacheは、**ファイルを置くとURLになる**方式。
- Flaskは、**関数とURLをコードで対応付ける**方式。
- 本講座では、ゲーム（Unity）から呼び出すAPIを作るため、Pythonだけで完結し、第02週のデータ型をそのまま使えるFlaskを採用する。

### 補足: 開発用サーバーと本番運用
Flaskに内蔵されている開発用サーバーは、学習・動作確認用。本番運用では、ApacheやNginxなどのWebサーバーと組み合わせて公開するのが一般的で、Flaskと排他的な関係ではない。本講座では開発用サーバーのみ使う。

## 3. 仮想マシンへの導入から起動まで

### 手順(1)：仮想環境の有効化

### 手順(2)：Flaskのインストール
仮想環境が有効な状態で実行する。

```bash
pip install flask
```

確認:

```bash
python3 -c "import flask; print(flask.__version__)"
pip list
```

`pip install`は仮想環境内に入るため、他の環境に影響しない（第01週のvenvの説明を参照）。

### 手順(3)：最小のFlaskアプリを作成
`~/class_python/app.py`を作成し、以下を保存する。

```python
# app.py
from flask import Flask

app = Flask(__name__)


@app.route("/")
def hello():
	return "Hello World"


if __name__ == "__main__":
	app.run(host="0.0.0.0", port=5000, debug=True)
```

コードの意味:
- `Flask(__name__)`: Flaskアプリ本体を作る。
- `@app.route("/")`: URL`/`にアクセスされたとき、直下の関数を実行する（**ルーティング**）。
- `return "Hello World"`: ブラウザに返す内容。
- `host="0.0.0.0"`: 仮想マシン外（Windows側）からの接続も受け付ける指定。仮想マシン内だけで使う場合は`127.0.0.1`でよい。
- `port=5000`: 待ち受けるポート番号。
- `debug=True`: 開発用の設定。コード変更時の自動再起動とエラー詳細表示を有効にする。学習用であり、公開環境では使わない。

### 手順(4)：起動
```bash
python3 app.py
```

次のような表示が出れば起動成功。

```text
 * Running on http://127.0.0.1:5000
```

停止はターミナルで`Ctrl + C`。

### 手順(5)：仮想マシン内で動作確認
サーバーを起動したターミナルは使用中になるため、**新しいターミナルを開いて**実行する。

```bash
curl http://127.0.0.1:5000/
```

`Hello World`と表示されれば成功。仮想マシン内のブラウザで`http://127.0.0.1:5000/`を開いてもよい。

### 手順(6)：Windowsのブラウザから確認（ポートフォワーディング）
VirtualBoxの標準設定（NAT）では、Windows側から仮想マシンへ直接接続できない。ポートフォワーディングを設定する。

1. 仮想マシンを**停止**した状態で、VirtualBoxの「設定」→「ネットワーク」→「高度」→「ポートフォワーディング」を開く。
2. 新しいルールを追加する。

| 項目 | 値 |
| ---- | -- |
| 名前 | flask |
| プロトコル | TCP |
| ホストIP | 127.0.0.1 |
| ホストポート | 5000 |
| ゲストIP | （空欄） |
| ゲストポート | 5000 |

3. 仮想マシンを起動し、Flaskを`python3 app.py`で起動する。
4. Windowsのブラウザで`http://127.0.0.1:5000/`を開く。

うまく表示されない場合:
- Flaskが起動したままか確認する。
- `host="0.0.0.0"`になっているか確認する。
- ポートフォワーディングのポート番号が一致しているか確認する。
- Ubuntuのファイアウォール（ufw）が有効な場合は、5000番ポートを許可する。
  ```bash
  sudo ufw status
  ```

※ 他のPCからLAN経由で接続する設定は、第14週のデプロイで扱う。

## 4. ルーティングの基本
URLごとに別の関数を割り当てる。

```python
# app.py
from flask import Flask

app = Flask(__name__)


@app.route("/")
def index():
	return "Hello World"


@app.route("/about")
def about():
	return "これはFlask学習用のサーバーです"


@app.route("/hello/<name>")
def hello_name(name):
	return f"Hello, {name}!"


if __name__ == "__main__":
	app.run(host="0.0.0.0", port=5000, debug=True)
```

動作確認:

| URL | 表示 |
| --- | ---- |
| `http://127.0.0.1:5000/` | Hello World |
| `http://127.0.0.1:5000/about` | これはFlask学習用のサーバーです |
| `http://127.0.0.1:5000/hello/Taro` | Hello, Taro! |

- `<name>`のように書くと、URLの一部を関数の引数として受け取れる。
- 存在しないURLにアクセスすると、Flaskが自動的に`404 Not Found`を返す。

## 5. 第02週との接続: 辞書を使った表示
第02週で学んだ辞書・リストを使い、サーバー側のデータからページを生成する。

```python
# app.py
from flask import Flask

app = Flask(__name__)

players = [
	{"name": "A", "score": 950},
	{"name": "B", "score": 1330},
	{"name": "C", "score": 1210},
]


@app.route("/ranking")
def ranking():
	sorted_players = sorted(players, key=lambda p: p["score"], reverse=True)
	lines = []
	for i, p in enumerate(sorted_players, start=1):
		lines.append(f"{i}位 {p['name']} : {p['score']}")
	return "<br>".join(lines)


if __name__ == "__main__":
	app.run(host="0.0.0.0", port=5000, debug=True)
```

`http://127.0.0.1:5000/ranking`にアクセスし、スコア順の一覧が表示されることを確認する。

ここでは文字列（HTML）として返している。**辞書をJSON形式で返すWeb API**は、第04週で学ぶ。
