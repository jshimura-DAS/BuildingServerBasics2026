## 🔄 リクエスト/レスポンスの流れ（完全図）

```
┌──────────────────────────────────────────────────────────────────┐
│ ユーザーが ブラウザで chat.html を開く                           │
└──────────────────────────────────────┬───────────────────────────┘
									   │
	   ┌───────────────────────────────┴───────────────────────────┐
	   │                                                           │
   【ページロード】                                          【ユーザー操作】
  DOMContentLoaded                                        フォーム送信
	   │                                                           │
	   ↓                                                           ↓
  ┌─────────────────────────────┐                        ┌──────────────────────────────┐
  │ JavaScript: autoRefresh()   │                        │ HTML: <form method="POST">  │
  │ fetch('chat.php?action=get')│                        │                              │
  └──────────────┬──────────────┘                        └────────────┬─────────────────┘
				 │                                                    │
  【GET リクエスト】                        【POST リクエスト】
				 │                                                    │
				 ↓                                                    ↓
		 ┌──────────────────────────┐                    ┌─────────────────────────────┐
		 │ PHP: $action = 'get'     │                    │ PHP: REQUEST_METHOD='POST'  │
		 │ if ($action === 'get')   │                    │ handlePostMessage()         │
		 │ displayMessages()        │                    │   ├─ $_POST 取得             │
		 │   ├─ CSV 読込            │                    │   ├─ 入力値検証              │
		 │   ├─ parseCSVLine()      │                    │   ├─ csvEscape()            │
		 │   └─ HTML 生成           │                    │   ├─ CSV 追記               │
		 └──────────────┬───────────┘                    │   └─ displayResult()       │
						│                                 └────────────┬────────────────┘
						│                                              │
		【HTML レスポンス】                            【HTML レスポンス】
						│                                              │
	 <div class='message'>                            <h1>投稿完了</h1>
	 ...メッセージ HTML...                            <a href='chat.html'>戻る</a>
	 </div>                                                           │
						│                                              │
						↓                                              ↓
		 JavaScript に返却                          ユーザーが「戻る」をクリック
		 .then(html => {                                              │
			.innerHTML = html                          chat.html を再読込
		 })                                                            │
						│                                              │
						↓                                              ↓
	  【ブラウザで表示】                          【ページロードに戻る】
	  メッセージが画面に表示                       DOMContentLoaded 発火
						│                                              │
						│ 5秒待機                                     └──┐
						│                                               │
						└──────────────────────────────────────────────→┘
				 （繰り返し：5秒ごとに GET リクエスト）
```

## 🔑 重要な概念

### 1. GET vs POST

| 項目 | GET | POST |
|------|-----|------|
| 目的 | データ取得 | データ送信 |
| URL に見える | ◯ | ✗ |
| キャッシュ | ◯ | ✗ |
| ブックマーク | ◯ | ✗ |
| 用例 | メッセージ一覧取得 | メッセージ投稿 |
| Chat での使用 | 定期取得（5秒ごと） | フォーム送信 |

### 2. CSV の安全な処理

**エスケープ:**
```
入力: She said "Hello"
保存: "She said ""Hello"""
取得: She said "Hello"
```

**XSS 対策:**
```
入力: <script>alert('xss')</script>
表示: &lt;script&gt;alert(&#039;xss&#039;)&lt;/script&gt;
（テキストとして表示）
```

### 3. ファイルの安全操作

```
読み込み: chmod 644（所有者読み書き、他は読み込みのみ）
読み書き: chmod 666（全員読み書き可能）
```

## 📞 よくある質問

### Q: GET と POST を使い分けるルールは？
A: 一般的には以下：
- **GET**: データの取得・検索
- **POST**: データの作成・更新・削除

Chat では GET でメッセージ取得、POST で投稿しています。

### Q: なぜ CSV を使っているのか？
A: 学習用として：
- 実装が簡単
- データが人間に読みやすい
- ファイル権限の管理が簡単

本番環境では通常 SQLite/MySQL などのデータベースを使用します。

### Q: 5秒ごとの更新は遅くないか？
A: 学習用として十分。本番環境では：
- WebSocket（リアルタイム）
- Server-Sent Events（SSE）
などを使用します。

### Q: セキュリティは大丈夫か？
A: 学習用として基本的な対策は施されています：
- ✅ XSS 対策（htmlspecialchars）
- ✅ CSV インジェクション対策（エスケープ）
- ❌ CSRF 対策なし
- ❌ 認証機能なし

本番環境では追加対策が必要です。
